# Changelog

## [0.1.0] - 2026-03-09

[DEUTSCH]
- Initialer Beta-Release mit Fokus auf Race-Day Logik.
- 3 Erinnerungs-Modi: Auto, Fixed Interval, Calorie Auto.
- Smart-Pause: Pausierte Zeit wird nicht in das Defizit eingerechnet.
- Auto-Flow: Automatische Buchung fuer Geraete ohne Touchscreen.
- FIT-Analyse: Aufzeichnung von Defizit und Verbrauch fuer Garmin Connect.
- Relative Design: Skalierung fuer alle Displaytypen.

[ENGLISH]
- Initial Beta release focusing on race-day fueling logic.
- 3 Reminder Modes: Auto, Fixed Interval, Calorie Auto.
- Smart-Pause: Paused time is excluded from deficit calculations.
- Auto-Flow: Automatic intake booking for non-touch devices.
- FIT Analysis: Records deficit and consumption for Garmin Connect.
- Relative Design: Dynamic scaling for all device profiles.
